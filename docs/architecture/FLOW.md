```
│                        Knowledge Submission Flow (知识提交流程)               │

│  │  - content: 必填, 非空                                                 │ │
│  │  - format: 可选, 默认为 'markdown'                                     │ │
│  │  - requiredLevel: 可选, 默认为 0                                      │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │

│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Duplicate Detection (Optional) (重复检测，可选)     │ │
│  │  - 指纹匹配                                                           │ │

│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │

│  │  2. 记录 submittedBy 参与者                                           │ │

│                                    │                                         │
│                                    ▼                                         │

│  │  event: 'knowledge.submitted'                                         │ │
│  │  - actorId, teamId, entryId, timestamp                                │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Agent Review (Async) (智能体审核，异步)             │ │
│  │  - 正确性风险评估                                                     │ │
│  │  - 重复重新检查                                                       │ │
│  │  - 转换: submitted → agent-pass 或 agent-rejected                    │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Post-Commit Indexing (提交后索引)                   │ │
│  │  - 向量 embedding（如果是 agent-pass 或 approved）                    │ │
│  │  - 关键词提取                                                        │ │
│  │  - 图关系                                                            │ │
│  │  - 在 KnowledgeIndexStateRecord 中更新索引状态                       │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│                              Response (响应)                                 │

│  └────────────────────────────────────────────────────────────────────────┘ │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 3. 审核决策流程

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                        Review Decision Flow (审核决策流程)                   │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Reviewer Input (审核者输入)                                                  │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  CLI: trapmap review approve <entryId> [--notes "..."]               │ │
│  │  or API: POST /v1/knowledge/review                                   │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Request Validation (请求验证)                     │ │
│  │  - entryId: 必填, 有效的 EntityId                                   │ │
│  │  - decision: 必填, 'approved' | 'rejected'                          │ │
│  │  - notes: 可选, 如果拒绝则必填                                       │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Session & RBAC Check (会话 & RBAC 检查)          │ │
│  │  - 有效会话                                                         │ │
│  │  - 权限: knowledge:review                                           │ │
│  │  - 安全等级 >= 条目 requiredLevel                                    │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Entry Validation (条目验证)                      │ │
│  │  - 条目存在                                                         │ │
│  │  - 条目处于可审核状态（submitted, agent-pass）                     │ │
│  │  - 条目尚未被审核                                                   │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Store Transaction (存储事务)                     │ │
│  │  1. 创建 ReviewRecord                                               │ │
│  │  2. 更新 entry.lifecycleState                                       │ │
│  │     - 如果 decision === 'approved' 则为 'approved'                 │ │
│  │     - 如果 decision === 'rejected' 则为 'rejected'                 │ │
│  │  3. 设置 entry.approvedBy/rejectedBy                                │ │
│  │  4. 追加到 entry.reviewHistory                                      │ │
│  │  5. 更新 entry.updatedAt                                           │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Audit Event Recording (审计事件记录)              │ │
│  │  event: 'knowledge.reviewed'                                       │ │
│  │  - actorId, entryId, decision, notes                                │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │                    Post-Commit Indexing (如果批准则提交后索引)       │ │
│  │  - 添加到向量索引                                                   │ │
│  │  - 添加到关键词索引                                                 │ │
│  │  - 添加到图索引（关系）                                             │ │
│  │  - 更新所有适配器的索引状态                                         │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│                              Response (响应)                                │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  { entryId, lifecycleState, reviewedBy, reviewedAt }                 │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

```

│  │  - 分配 EntityId                                                       │ │
│  │  - 记录 submittedAt, submittedBy                                     │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │

│  │  - 拾取 status: 'received' 的候选项                                   │ │

│  │  - 加入处理队列                                                       │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  Processing Stage (处理阶段)                                          │ │
│  │  1. 更新状态为 'analyzing'                                             │ │
│  │  2. 生成指纹（内容的哈希）                                             │ │
│  │  3. 生成 embedding（用于语义相似度）                                   │ │
│  │  4. 检查与现有条目的指纹匹配                                           │ │
│  │  5. 检查与现有条目的语义相似度                                         │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                      ┌─────────────┴─────────────┐                         │
│                      ▼                           ▼                          │
│  ┌────────────────────────┐         ┌────────────────────────┐            │
│  │  Duplicate Detected    │         │  Analysis Complete     │            │
│  │  (检测到重复)           │         │  (分析完成)             │            │

│  │  - matchType: fingerprint │       │  - status: ready_for  │            │
│  │    或 semantic          │         │    review             │            │
│  │  - status: duplicate_detected │   │                        │            │
│  └────────────┬─────────────┘         └────────────┬─────────┘            │
│               │                                      │                       │
│               │                                      │                       │
│               ▼                                      ▼                       │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  Reviewer Action Required (需要审核者操作)                           │ │
│  │  GET /v1/duplicates/:candidateId/bundle                              │ │
│  │  - 显示候选和重复项                                                   │ │
│  │  - 允许人工解决                                                       │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  Manual Resolution (人工解决)                                         │ │
│  │  POST /v1/candidates/:id/manual-result                                │ │

│  │                                                                          │ │

│  │  - 'discard': 拒绝候选                                                 │ │
│  │  - 'keep_both': 将两者都发布为独立条目                                  │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                         │
│                                    ▼                                         │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  Resolution Applied (解决方案已应用)                                  │ │
│  │  - status: 'resolved'                                                 │ │
│  │  - 创建 trap 或 skill 条目（如果是发布）                               │ │
│  │  - 通过 EntityLineage 链接候选到实体                                  │ │
│  │  - 在 DuplicateCase 中记录解决方案                                    │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```
