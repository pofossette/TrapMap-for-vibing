# FM-Agent Scan Plans

This directory contains the reconciled planning artifacts for the FM-agent raw report remediation work.

Contents:

- `contracts-fix-plan.md`
- `cli-fix-plan.md`
- `server-fix-plan.md`
- `contracts-live-gap-matrix.md`
- `cli-live-gap-matrix.md`
- `server-live-gap-matrix.md`
- `contracts-source-pack.md`
- `cli-source-pack.md`
- `server-source-pack.md`

Usage notes:

1. Root [`plan.md`](../../../plan.md) remains the execution index.
2. `*-fix-plan.md` files are the per-package execution plans.
3. `*-live-gap-matrix.md` files contain the reconciled current-HEAD classification of raw findings.
4. `*-source-pack.md` files preserve the raw-report to current-source crosswalk used during triage.
