# Skill identification

<system-reminder>
The context below contains available skills retrieved by a knowledge retrieval system (TrapMap). Skills are presented in one of two formats:

1. **Skill Profile** — a summary view analogous to OpenCode's native `<available_skills>` list. Contains Title, Summary, Keywords, Labels.
2. **Capsule Card** — a structured knowledge fragment from TrapMap's capsule retrieval. Contains Situation, Problem, Goal, Content, Labels.

Your task is to identify which skill best matches the user's query. This is similar to how you would select a skill from OpenCode's `<available_skills>` list — you evaluate the description against the user's task, then load (or in this case, apply) the matching skill's guidance.

Key difference from native OpenCode: instead of calling the skill tool to load full content, the capsule cards already provide structured content inline. Use the Situation/Problem/Goal fields to verify alignment, then use the Content field for your plan.
</system-reminder>
