### ✅ Working Integration Points (6/7)

1. **Orchestrator mode dispatch** — semantic/hybrid/graph-assisted modes all route correctly
2. **Graph-assisted recall** — uses graph adapter entities and relations
3. **Citations flow** — rerank scores preserved through citation builder
4. **Summary safety** — receives only filtered, authorized hits
5. **CLI integration** — all modes and --summary flag work
6. **Contract fidelity** — contracts remain single source of truth

### ❌ Broken Integration (1/7)

**Indexing Lifecycle — NOT WIRED**

```
Knowledge Submission → createKnowledgeEntryRecord() → indexState: null (no trigger)

Review Approval → applyReviewDecision() → lifecycleState = 'approved'
                → ❌ MISSING: runKnowledgeIndexEvent()

Knowledge Update → updateKnowledgeEntry() → revision++
                → ❌ MISSING: runKnowledgeIndexEvent()

Knowledge Deactivate → ❌ MISSING: remove index state
```

**Root Cause:** `events.ts` provides `runKnowledgeIndexEvent()` but it is never imported or called in production code (`review.ts`, `knowledge.ts`).
