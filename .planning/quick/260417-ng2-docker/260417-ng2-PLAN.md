# Plan: Docker Configuration for Server

## Overview

Provide Docker configuration for the `@skill-shareer/server` package to enable containerized deployment.

## Tasks

### Task 1: Create Dockerfile for Server Package

**Files:**
- `packages/server/Dockerfile` (create)

**Action:**
Create a production-ready multi-stage Dockerfile that:
- Uses Node.js 22 LTS Alpine as base image
- Installs pnpm via corepack
- Copies workspace root package.json + pnpm-lock.yaml for dependency caching
- Copies contracts package (server depends on it)
- Copies server package
- Builds TypeScript in a build stage
- Creates a minimal production image with only dist/ and production node_modules
- Sets appropriate environment variables (NODE_ENV=production, HOST=0.0.0.0)
- Exposes port 4000
- Runs `node dist/index.js` as entrypoint

**Verify:**
- Dockerfile syntax is valid
- Build stages are properly separated
- Production image is minimal

**Done:**
- Dockerfile exists at `packages/server/Dockerfile`

### Task 3: Create docker-compose.yml for Local Development

**Files:**
- `docker-compose.yml` (create at repo root)

**Action:**
Create a docker-compose.yml that:
- Builds the server from `packages/server/Dockerfile`
- Maps port 4000:4000
- Mounts a volume for data persistence (`./.data:/app/.data`)
- Sets required environment variables:
  - `OPENAI_API_KEY` (from host env or .env file)
  - `SKILL_SHAREER_DATA_FILE=/app/.data/skill-shareer.json`
  - `SKILL_SHAREER_SYSTEM_ADMIN_KEY` (optional)
- Includes healthcheck using `curl http://localhost:4000/health` or similar

**Verify:**
- docker-compose syntax is valid
- Service can start with `docker compose up`

**Done:**
- `docker-compose.yml` exists at repo root
