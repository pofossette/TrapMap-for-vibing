<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| normalized knowledge text -> entity extractor | extractor rules determine what becomes a graph node |
| entity extractor -> graph adapter payload | noisy or inconsistent extraction could poison later graph recall |
| graph adapter payload -> persisted store | graph data must remain internal and removable by revision/content-hash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Tampering | `graph-extract.ts` | mitigate | keep extraction deterministic, field-aware, and covered by explicit tests for required entity classes |
| T-09-05 | Information Disclosure | stored graph artifacts | mitigate | keep graph entities and relations server-internal and avoid public contract changes |
| T-09-06 | Denial of Service | graph artifact growth | mitigate | bound relation fan-out, dedupe normalized entity keys, and keep only one-hop adjacency-ready metadata |
</threat_model>
