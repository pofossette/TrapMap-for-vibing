<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| normalized document -> adapter state | adapter persistence must not drift from the canonical Phase 8 document |
| persisted adapter state -> retrieval recall | recall consumers must not trust stale or mismatched index payloads blindly |
| recall fallback -> hot path | fallback must stay bounded to legacy unsynced entries, not become the default path again |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-09 | Tampering | `vector.ts` / `keyword.ts` | mitigate | key persisted payloads by `revision` and `contentHash`, and test stale rewrite skipping plus idempotent remove |
| T-08-10 | Information Disclosure | `semantic.ts` / `keyword.ts` | mitigate | keep adapters authorization-agnostic and consume only entries already filtered by the orchestrator |
| T-08-11 | Denial of Service | recall fallback path | mitigate | prefer persisted state first and allow recomputation only for legacy entries lacking synced payloads |
| T-08-12 | Integrity | compatibility bridge via `embeddingCache` | mitigate | mirror vector writes during migration and keep tests asserting persisted state and compatibility remain aligned |
</threat_model>
