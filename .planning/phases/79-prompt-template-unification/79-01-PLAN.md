# Phase 79-01: Prompt Template Unification

## Goal

Consolidate prompt templates across the codebase into a unified, maintainable system using LangChain's prompt template utilities.

## Context

Three inline prompt templates have been identified:

1. **Claim Verification** (`evals/summary/lib/judge.ts:110-113`)
2. **Boundary Extraction** (`packages/server/src/lib/boundary-extract.ts:31-54`)
3. **Knowledge Refinement** (`packages/server/src/lib/retrieval/orchestrator.ts:931`)

These prompts are currently hardcoded inline, making them hard to version, cache, and maintain.

## Design

### Architecture

```
packages/server/src/lib/ai/prompts/
├── index.ts          # Public exports
├── types.ts          # PromptTemplateId, PromptMetadata types
└── templates.ts      # Template definitions and format functions
```

### Key Design Decisions

1. **Use LangChain's `ChatPromptTemplate`** from `@langchain/core/prompts` for type-safe templating
2. **Maintain backward compatibility** with `ChatProvider.invoke(systemPrompt, userMessage)` by providing format functions that return string tuples
3. **Add versioning metadata** to each template for future caching and A/B testing support
4. **Keep templates pure** - no side effects, just formatting

```typescript
/**
 * Format claim verification prompt.
 * Returns [systemPrompt, userMessage] tuple for ChatProvider.invoke().
 */
export function formatClaimVerificationPrompt(
  input: ClaimVerificationInput,
): FormattedPrompt {
  const contextFormatted = input.context
    .map((c, i) => `[${i + 1}] ${c}`)
    .join('\n\n');

  const claimsFormatted = input.claims
    .map((c, i) => `${i + 1}. ${c.text}`)
    .join('\n');

  // Use template.formatMessages for type safety, then extract strings
  // For simplicity with ChatProvider's string-based API, we format directly
  const systemPrompt = `You are a claim verification assistant.
Your task is to verify if claims from a summary are supported by the provided context.
For each claim, determine if it is supported by the context and provide evidence if available.
Be strict - only mark a claim as supported if the context directly supports it.`;

  const userMessage = `Context:
${contextFormatted}

Claims to verify:
${claimsFormatted}

For each claim, respond in JSON format:
{"verifications": [{"claimIndex": 0, "supported": true/false, "evidence": "quote from context or null"}]}`;

  return [systemPrompt, userMessage];
}
```

```typescript
/**
 * Generate a refinement summary for search results.
 * This is best-effort: returns null if no provider is configured.
 *
 * @param services - Server services (for AI chat provider)
 * @param query - The original search query
 * @param globalConstraints - Matched global constraints
 * @param projectKnowledge - Matched project knowledge
 * @returns A summary string or null if refinement is unavailable
 */
async function generateRefinement(
  services: SkillShareerServices,
  query: string,
  globalConstraints: unknown[],
  projectKnowledge: unknown[],
): Promise<string | null> {
  // Best-effort: only refine if a provider is configured
  if (!isRefinementAvailable(services)) {
    return null;
  }

  // If we have no matches, return null (nothing to refine)
  if (globalConstraints.length === 0 && projectKnowledge.length === 0) {
    return null;
  }

  try {
    // Use centralized prompt template
    const [systemPrompt, userMessage] = formatKnowledgeRefinementPrompt({
      query,
      searchResults: buildRefinementPrompt(query, globalConstraints, projectKnowledge),
    });

    return await services.ai.chat.invoke(systemPrompt, userMessage);
  } catch {
    // Graceful degradation: if LLM call fails, return null
    return null;
  }
}
```
