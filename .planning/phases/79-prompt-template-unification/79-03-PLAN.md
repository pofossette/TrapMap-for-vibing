# Phase 79-03: Simplify Prompt Templates

## Goal

Remove redundant LangChain `ChatPromptTemplate` imports and use pure string-based templates.

## Context

Wave 1 created the prompt module with LangChain's `ChatPromptTemplate.fromMessages()`. However, the format functions immediately extract strings anyway, making the LangChain imports redundant. This plan simplifies the implementation by:

1. Removing `ChatPromptTemplate` imports and constants
2. Using simple string constants for system prompts
3. Keeping the format functions unchanged (they already return strings)

### Why This Matters

- **Reduced bundle overhead**: LangChain templates add ~5KB for no benefit
- **Simpler code**: No intermediate template objects
- **Same functionality**: `ChatProvider.invoke()` requires string arguments anyway
- **Easier testing**: Direct string comparison without template abstraction

3. Apply same pattern to all three templates:
   - `CLAIM_VERIFICATION_SYSTEM_PROMPT`
   - `BOUNDARY_EXTRACTION_SYSTEM_PROMPT`
   - `KNOWLEDGE_REFINEMENT_SYSTEM_PROMPT`

4. Update format functions to use the string constants instead of template objects.

**Example for claim verification:**
```typescript
export function formatClaimVerificationPrompt(
  input: ClaimVerificationInput,
): FormattedPrompt {
  const contextFormatted = input.context
    .map((c, i) => `[${i + 1}] ${c}`)
    .join('\n\n');

  const claimsFormatted = input.claims
    .map((c, i) => `${i + 1}. ${c.text}`)
    .join('\n');

  const userMessage = `Context:
${contextFormatted}

Claims to verify:
${claimsFormatted}

For each claim, respond in JSON format:
{"verifications": [{"claimIndex": 0, "supported": true/false, "evidence": "quote from context or null"}]}`;

  return [CLAIM_VERIFICATION_SYSTEM_PROMPT, userMessage];
}
```
