# Plan 21-02: Integrate User Ops Logging into API Routes

## Goal

Add explicit `logUserOperation` calls to all user-facing route handlers to log operations: search, submit, edit, review, import, and export. This completes the LOG-01 requirement.

## Context

- **LOG-01**: Server logs user operations with actor, action, target, and timestamp
- **Integration pattern**: Fire-and-forget with `void logUserOperation(...)` after successful operations
- **Action types**: search, submit, edit, review, review-list, import, export
- **Log entry fields**: timestamp, actorId, actorHandle, action, targetId, teamId, metadata
- **Config access**: `app.skillShareer.config.userOpsLog`

```typescript
import { readFile } from 'node:fs/promises';
import { existsSync } from 'node:fs';
import path from 'node:path';

describe('user ops logging integration', () => {
  it('does not write log files when LOG_USER_OPS_ENABLED is false (default)', async () => {
    // Default buildServer does not enable logging
    const app = buildServer();
    await app.ready();

    // Make a request that would be logged if enabled
    const response = await app.inject({
      method: 'POST',
      url: '/v1/retrieval/search',
      payload: {
        seed: 'test query',
        filters: { labels: [], scopes: [] },
        maxResults: 10,
        includeRefinement: false,
      },
    });

    // Request should fail auth, but no log should be created
    expect(response.statusCode).toBe(401);

    await app.close();
  });

  it('writes log file when LOG_USER_OPS_ENABLED is true', async () => {
    const tempLogDir = `/tmp/test-logs-${Date.now()}`;

    // Set env vars before building server
    const originalEnv = process.env.LOG_USER_OPS_ENABLED;
    const originalDir = process.env.LOG_USER_OPS_DIR;
    process.env.LOG_USER_OPS_ENABLED = 'true';
    process.env.LOG_USER_OPS_DIR = tempLogDir;

    try {
      const app = buildServer();
      await app.ready();

      // Create a session for authenticated request
      // ... setup user, team, membership, session ...

      // Make an authenticated search request
      const response = await app.inject({
        method: 'POST',
        url: '/v1/retrieval/search',
        headers: { authorization: `Bearer ${sessionId}` },
        payload: {
          seed: 'test query',
          filters: { labels: [], scopes: [] },
          maxResults: 10,
          includeRefinement: false,
        },
      });

      // Check log file was created
      const today = new Date().toISOString().split('T')[0];
      const logFile = path.join(tempLogDir, `${today}.log`);

      // Allow async log write to complete
      await new Promise(resolve => setTimeout(resolve, 100));

      if (existsSync(logFile)) {
        const content = await readFile(logFile, 'utf-8');
        const lines = content.trim().split('\n');
        expect(lines.length).toBeGreaterThan(0);

        const entry = JSON.parse(lines[0]);
        expect(entry).toHaveProperty('timestamp');
        expect(entry).toHaveProperty('actorId');
        expect(entry).toHaveProperty('action', 'search');
      }

      await app.close();
    } finally {
      process.env.LOG_USER_OPS_ENABLED = originalEnv;
      process.env.LOG_USER_OPS_DIR = originalDir;
    }
  });
});
```

</action>
