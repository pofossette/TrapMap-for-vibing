<objective>
Add the database-backed store foundation for Phase 43.

Purpose: replace the server's filesystem-only durability boundary with a compatibility-preserving PostgreSQL implementation while keeping the existing aggregate mutation model intact for current services.
Output: new shared store contract, Drizzle/PostgreSQL store implementation, runtime selection, and dependency/config wiring.
</objective>

    <action>
      Add the PostgreSQL/Drizzle runtime dependencies needed for a compatibility store, export a shared store interface from `store.ts`, and implement a PostgreSQL-backed store that persists one canonical `StoreData` snapshot row in JSONB while preserving the current `snapshot`, `transact`, and `nextId` contract. Use transactional row locking so writes stay serialized from the caller's point of view.
    </action>
    <acceptance_criteria>
      - `@trapmap/server` declares the database dependencies required by the new store

      - `packages/server/src/lib/persistence/postgres-store.ts` can load and persist `StoreData` through PostgreSQL
      - the PostgreSQL store creates or ensures its backing schema lazily instead of requiring a separate manual bootstrap just to start the server
    </acceptance_criteria>
  </task>
