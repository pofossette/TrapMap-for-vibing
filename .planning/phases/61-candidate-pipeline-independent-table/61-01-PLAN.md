    **Create `packages/server/src/lib/candidates/pg-repository.ts`:**

    Implement PgCandidateRepository following the task-queue.ts pattern (Pool + ensureSchema + drizzle instance). This class implements the CandidateRepository interface defined in repository.ts.

    Constructor takes `Pool` from pg. Uses `pool.connect()` + `BEGIN`/`COMMIT` for write operations that need row-level locking. Uses `pool.query()` for simple reads.

    Key implementation details for each method:

    1. **ensureSchema()**: Create the `candidates` table and indexes via raw SQL (matching task-queue.ts pattern):
       ```sql
       CREATE TABLE IF NOT EXISTS candidates (
         id TEXT PRIMARY KEY,
         source_type TEXT NOT NULL,
         submitted_by TEXT NOT NULL,
         team_id TEXT,
         status TEXT NOT NULL,
         original_payload JSONB NOT NULL,
         analysis_snapshot JSONB,
         duplicate_case JSONB,
         received_at TIMESTAMP WITH TIME ZONE NOT NULL,
         queued_at TIMESTAMP WITH TIME ZONE,
         analyzing_at TIMESTAMP WITH TIME ZONE,
         completed_at TIMESTAMP WITH TIME ZONE,
         last_error TEXT,
         retry_count INTEGER NOT NULL DEFAULT 0,
         manual_result JSONB,
         created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
         updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       );
       CREATE INDEX IF NOT EXISTS idx_candidates_status ON candidates (status);
       CREATE INDEX IF NOT EXISTS idx_candidates_team ON candidates (team_id) WHERE team_id IS NOT NULL;
       ```

    2. **insert(candidate)**: Use `db.insert(candidates).values(...)` to insert the row. Map CandidateSubmission fields to snake_case column names. Call `ensureSchema()` first.

    3. **getById(candidateId)**: Use `db.select().from(candidates).where(eq(candidates.id, candidateId))`. Return null if not found. Map snake_case columns back to CandidateSubmission shape.

    4. **updateStatus(candidateId, status, error?)**: Use `pool.connect()` + `BEGIN` + `SELECT ... FOR UPDATE` for row-level locking:
       ```typescript
       const client = await this.pool.connect();
       try {
         await client.query('BEGIN');
         const { rows } = await client.query('SELECT id FROM candidates WHERE id = $1 FOR UPDATE', [candidateId]);
         if (rows.length === 0) throw new Error(`Candidate ${candidateId} not found`);
         const now = new Date().toISOString();
         // Set status-specific timestamp columns
         const timestampCol = status === 'queued' ? 'queued_at'
           : status === 'analyzing' ? 'analyzing_at'
           : ['ready_for_review', 'duplicate_detected', 'error', 'resolved', 'rejected'].includes(status) ? 'completed_at'
           : null;
         if (status === 'error') {
           await client.query(
             'UPDATE candidates SET status = $1, completed_at = $2, last_error = $3, retry_count = retry_count + 1, updated_at = $2 WHERE id = $4',
             [status, now, error ?? 'Unknown error', candidateId],
           );
         } else if (timestampCol) {
           await client.query(
             `UPDATE candidates SET status = $1, ${timestampCol} = $2, updated_at = $2 WHERE id = $3`,
             [status, now, candidateId],
           );
         } else {
           await client.query(
             'UPDATE candidates SET status = $1, updated_at = $2 WHERE id = $3',
             [status, now, candidateId],
           );
         }
         await client.query('COMMIT');
       } catch (e) {
         await client.query('ROLLBACK').catch(() => {});
         throw e;
       } finally {
         client.release();
       }
       ```

    5. **attachAnalysis(candidateId, snapshot)**: Use `pool.connect()` + `SELECT ... FOR UPDATE` + `UPDATE candidates SET analysis_snapshot = $1, updated_at = $2 WHERE id = $3`.

    6. **attachDuplicateCase(candidateId, duplicateCase)**: Use same locking pattern. `UPDATE candidates SET duplicate_case = $1, updated_at = $2 WHERE id = $3`.

    7. **attachManualResult(candidateId, result, reviewedBy)**: Construct `ManualResultRecord` from `result` + `submittedAt`/`submittedBy`, then `UPDATE candidates SET manual_result = $1, updated_at = $2 WHERE id = $3`.

    8. **listByStatus(status)**: `db.select().from(candidates).where(eq(candidates.status, status))`. Map all rows back to CandidateSubmission shape.

    9. **markResolved(candidateId, resolvedBy)**: Update status='resolved', completedAt=now, updatedAt=now.
