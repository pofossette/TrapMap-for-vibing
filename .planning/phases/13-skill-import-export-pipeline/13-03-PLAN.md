## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored artifact payloads -> export projections | only governed artifacts and approved file-role boundaries may be exported |
| server export response -> CLI local writer | the CLI must treat output paths as untrusted and avoid traversal/overwrite surprises |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-08 | Information Disclosure | export projections | mitigate | build `distilled-json` from cached derived outputs and omit private sidecars from standard `skill-dir` materialization by default |
| T-13-09 | Elevation of Privilege | `POST /v1/operations/export` | mitigate | preserve current permission, team, and security-level filtering before projecting any artifact data |
| T-13-10 | Repudiation | export audit trail | mitigate | record audit events with artifact ids, team filter, and requested export format in the same transaction pattern used today |
| T-13-11 | Tampering | CLI `skill-dir` writer | mitigate | reject unsafe output paths, normalize local writes, and materialize only canonical relative paths from the bundle payload |
</threat_model>
