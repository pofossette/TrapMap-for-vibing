# CLI Operations Refactoring — Wave 2: Extract Command Modules

**Objective:** Extract 9 command registrations from `operations.ts` into individual sub-modules under `operations/` directory, following the pattern established in Phase 80 server-side refactoring.

## Module Structure

```
packages/cli/src/commands/
├── operations.ts           # Thin router (~50 lines) - Wave 3
└── operations/
    ├── index.ts            # Barrel export
    ├── types.ts            # OperationsCommandOptions interface
    ├── list.ts             # list command (~60 lines)
    ├── edit.ts             # edit command (~70 lines)
    ├── deactivate.ts       # deactivate command (~40 lines)
    ├── export.ts           # export + artifact-export (~130 lines)
    ├── import.ts           # import command (~160 lines)
    ├── activate.ts         # activate command (~140 lines)
    ├── migrate.ts          # migrate command (~90 lines)
    └── status.ts           # status command (~50 lines)
```
