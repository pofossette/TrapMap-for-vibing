- Mock `../lib/config.js` (loadCliState, updateCliState)

2. Handles entry without agentReview
3. Handles entry without reviewHistory

7. Submits with required options (scope, label, shortcut)
8. Reads detail from --file option

10. Throws on invalid boundary JSON
11. Requires authentication
12. Outputs formatted result

**resubmit command (5 tests):**
13. Resubmits with entryId and required options
14. Reads updated detail from stdin
15. Parses boundary JSON option
16. Requires authentication
17. Outputs formatted result with revision number

**supersede command (3 tests):**
18. Supersedes entry with replacement ID
19. Requires authentication
20. Outputs formatted result

**review-status command (5 tests):**

23. Requires authentication
24. Formats entry output
25. Formats history output
