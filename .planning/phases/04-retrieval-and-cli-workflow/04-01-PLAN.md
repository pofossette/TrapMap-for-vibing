<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI/client -> `/v1/retrieval/search` | Untrusted search seed and filters enter the API. |
| retrieval service -> JSON store | Stored knowledge may contain unauthorized or unapproved records that must not leak into search results. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | I | `packages/server/src/lib/retrieval.ts` | mitigate | Filter by approval state, active team, and `requiredLevel` before ranking so unauthorized entries never affect results. |
| T-04-02 | T | `packages/server/src/routes/retrieval.ts` | mitigate | Parse body with `retrievalQuerySchema` and reuse Fastify/Zod error handling to reject malformed input. |
| T-04-03 | D | retrieval ranking path | accept | Keep deterministic in-process scoring for v1 and cap `maxResults` with existing schema limits to bound work. |
</threat_model>
