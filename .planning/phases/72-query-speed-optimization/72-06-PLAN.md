# PLAN 72-06: Integrate DB-level search into retrieval orchestrator

## Problem

The retrieval orchestrator still uses in-memory search even after DB-level search functions are added. The new `vectorSimilaritySearch()` and `keywordSearchDb()` functions from plans 72-04 and 72-05 need to be integrated into the main retrieval path.

## Solution

Modify the orchestrator to use DB-level search when PostgreSQL is available:

1. **Add feature flag** for DB-level search:
   - `USE_DB_SEARCH=true` environment variable
   - Falls back to in-memory if DB search fails

2. **Modify `semanticRecall()`**:
   - Check if DB search is enabled and pool is available
   - Use `vectorSimilaritySearch()` for candidate retrieval
   - Apply in-memory scoring to DB results

3. **Modify `hybridRecall()`**:
   - Use `vectorSimilaritySearch()` for semantic channel
   - Use `keywordSearchDb()` for keyword channel
   - Merge and rerank as before

4. **Add metrics**:
   - Log which search path was used
   - Track DB search latency separately

## Implementation

```typescript
// packages/server/src/lib/retrieval/orchestrator.ts

interface DbSearchConfig {
  enabled: boolean;
  pool: Pool | null;
}

function getDbSearchConfig(): DbSearchConfig {
  return {
    enabled: process.env.USE_DB_SEARCH === 'true',
    pool: services.store instanceof PostgresStore ? services.store.getPool() : null,
  };
}

async function semanticRecall(
  seed: string,
  eligibleEntries: KnowledgeRecord[],
  parsed: ReturnType<typeof retrievalQuerySchema.parse>,
): Promise<{ scoredEntries: ScoredEntry[]; mergedCandidates?: MergedCandidate[] }> {
  const dbConfig = getDbSearchConfig();

  if (dbConfig.enabled && dbConfig.pool) {
    // Use DB-level vector search
    const queryVector = await getQueryEmbedding(seed);
    const dbResults = await vectorSimilaritySearch(dbConfig.pool, {
      queryVector,
      limit: parsed.maxResults * 2, // Get extra for reranking
    });

    // Convert DB results to scored entries
    return convertDbResultsToScoredEntries(dbResults, eligibleEntries);
  }

  // Fall back to in-memory search
  // ... existing implementation
}
```
