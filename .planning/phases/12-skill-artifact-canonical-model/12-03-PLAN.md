## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest content -> derived text outputs | only selected files may enter model-context-shaped outputs |
| derived outputs -> downstream retrieval/activation phases | later phases will trust these cached shapes instead of reparsing source files |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-09 | Tampering | `packages/server/src/lib/artifacts/derive.ts` | mitigate | derive hashes from ordered `SKILL.md` + `references/` text only and generate stable `capsuleId` values from revision-scoped content hashes |
| T-12-10 | Information Disclosure | `packages/server/src/lib/artifacts/derive.ts` | mitigate | exclude `assets/` and `scripts/` bodies from profile/capsule content and expose them only through `clientManifest` metadata |

| T-12-12 | Denial of Service | `packages/server/src/lib/artifacts/derive.ts` | mitigate | keep derivation deterministic and revision-scoped with cached outputs so downstream phases do not repeatedly recompute or reparse the same files |
</threat_model>
