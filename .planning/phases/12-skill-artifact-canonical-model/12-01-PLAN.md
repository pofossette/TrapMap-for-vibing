## Trust Boundaries

|----------|-------------|
| shared contracts -> server/CLI consumers | every later implementation imports these schemas as the only shared truth |
| artifact manifest -> derived-output contracts | file classification controls whether content may become model context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Tampering | `packages/contracts/src/domain/artifacts.ts` | mitigate | encode explicit file kinds and `includeInDerivation` / `activationOnly` flags so downstream code cannot silently flatten `references/`, `assets/`, and `scripts` |
| T-12-02 | Information Disclosure | `packages/contracts/src/domain/artifacts.ts` | mitigate | make `clientManifestScriptSchema` metadata-only and exclude script bodies from `skillCapsuleSchema` and `skillProfileSchema` |
| T-12-03 | Denial of Service | `packages/contracts/src/index.ts` | mitigate | keep artifact schemas additive in a new module so legacy `knowledge` imports remain stable during the Phase 12-16 coexistence window |
| T-12-04 | Elevation of Privilege | `packages/contracts/src/domain/artifacts.ts` | mitigate | carry `scope` and `requiredLevel` on artifact and capsule contracts so downstream retrieval/activation code cannot invent looser governance |
</threat_model>
