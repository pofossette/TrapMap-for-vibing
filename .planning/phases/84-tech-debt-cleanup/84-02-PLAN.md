# Phase 84-02: Dead Code Cleanup - Unused Type Exports

## Objective

Remove `export` keyword from types/interfaces that are only used internally within their modules. This eliminates knip warnings for unused exports while preserving the types for internal use.

## Tasks

### Task 1: Unexport unused types from graph-extract.ts

<read_first>
- packages/server/src/lib/retrieval/graph-extract.ts (contains types to unexport)
</read_first>

<action>
Remove `export` keyword from types that are only used internally. These types are used by functions within the file but never imported by other files:

1. Lines 31-36: Change `export interface GraphNode` to `interface GraphNode` (used internally by extractTrapNode, etc.)
2. Lines 41-47: Change `export interface GraphRelation` to `interface GraphRelation` (used internally)
3. Lines 52-55: Change `export interface TrapGraphExtractionResult` to `interface TrapGraphExtractionResult` (used by extractTrapGraphEntities)
4. Lines 656-663: Change `export type LegacyGraphEntityType` to `type LegacyGraphEntityType` (deprecated, internal only)
5. Lines 668-675: Change `export type LegacyGraphRelationType` to `type LegacyGraphRelationType` (deprecated, internal only)
6. Lines 680-685: Change `export interface GraphEntity` to `interface GraphEntity` (deprecated, internal only)
7. Lines 690-696: Change `export interface LegacyGraphRelation` to `interface LegacyGraphRelation` (deprecated, internal only)
8. Lines 701-705: Change `export interface GraphExtractionResult` to `interface GraphExtractionResult` (deprecated, internal only)

Also remove the re-exports on line 26:
```typescript
// REMOVE this line:
export type { GraphNodeKind, GraphRelationType, GraphRelationStrength };
```

These types are already imported from `../indexing/graph-lite/documents.js` and re-exporting them causes knip warnings.
</action>
