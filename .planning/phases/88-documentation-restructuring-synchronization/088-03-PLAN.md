## 反馈端点

### POST /v1/feedback

提交知识条目反馈。

**请求**:
```json

  "entryId": "entry-xxx",
  "feedbackType": "helpful" | "not_helpful" | "outdated" | "incorrect",

  }

```

**响应** (201):
```json
{
  "id": "feedback-xxx",
  "entryId": "entry-xxx",
  "feedbackType": "helpful",
  "createdAt": "2026-05-06T12:00:00Z"
}
```

---

### GET /v1/feedback

列出反馈（用户查看自己的反馈）。

**查询参数**:
- `limit`: 数量限制 (默认 20)
- `entryId`: 按条目过滤

**响应** (200):
```json
{
  "feedbacks": [
    {
      "id": "feedback-xxx",
      "entryId": "entry-xxx",
      "feedbackType": "helpful",
      "comment": "Very useful guide",
      "createdAt": "2026-05-06T12:00:00Z"
    }
  ]
}
```

---

### GET /v1/feedback/stats/:entryId

获取条目的反馈统计。

**响应** (200):
```json
{
  "entryId": "entry-xxx",
  "total": 15,
  "breakdown": {
    "helpful": 10,
    "not_helpful": 2,
    "outdated": 2,
    "incorrect": 1
  }
}
```

---

## 管理员反馈端点

### GET /v1/admin/feedback

管理员获取所有反馈列表。

**查询参数**:
- `limit`: 数量限制
- `offset`: 分页偏移
- `feedbackType`: 按类型过滤
- `startDate`: 开始日期
- `endDate`: 结束日期

**响应** (200):
```json
{
  "feedbacks": [
    {
      "id": "feedback-xxx",
      "entryId": "entry-xxx",
      "entryTitle": "OAuth2 Setup Guide",
      "feedbackType": "outdated",
      "comment": "This guide is for old version",
      "submittedBy": "user-xxx",
      "createdAt": "2026-05-06T12:00:00Z"
    }
  ],
  "total": 150
}
```

  "notes": "Action taken to address feedback"
}
```

**响应** (200):
```json
{
  "id": "feedback-xxx",
  "status": "resolved",
  "resolvedAt": "2026-05-06T14:00:00Z",

}
```
```
