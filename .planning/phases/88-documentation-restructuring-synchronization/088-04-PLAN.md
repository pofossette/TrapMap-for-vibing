### `trapmap operations import`

导入知识条目。

```bash
trapmap operations import <file> [--format <format>] [--skip-duplicates]
```

**示例**:
```bash
trapmap operations import ./knowledge-export.json
trapmap operations import ./knowledge.yaml --format yaml --skip-duplicates
```

**选项**:
- `--format, -f`: 文件格式 (json, yaml)，默认根据扩展名
- `--skip-duplicates`: 跳过重复条目

---

### `trapmap operations export`

导出知识条目。

```bash
trapmap operations export [--file <file>] [--format <format>] [--filter <filter>]
```

**示例**:
```bash
trapmap operations export --file ./export.json --format json
trapmap operations export --filter '{"level":{"lte":3}}'
```

---

### `trapmap operations activate`

激活工件或胶囊。

```bash
trapmap operations activate <artifactId> [--capsules <ids>]
```

**示例**:
```bash
trapmap operations activate artifact-xxx
trapmap operations activate artifact-xxx --capsules capsule-1,capsule-2
```

**输出**:
```
✓ Artifact activated: artifact-xxx
  Activated capsules: 2
```

---

### `trapmap operations deactivate`

停用知识条目或工件。

trapmap operations deactivate <entryId> [--reason <reason>]

  State: deactivated
