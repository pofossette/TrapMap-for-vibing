# Phase 2 Plan 03: CLI Auth, Teams, and Visibility

## Objective
- **What:** Turn the CLI bootstrap into a real authenticated terminal client for team and member management.
- **Why:** The CLI is the primary user surface and must respect authenticated permissions before later features are added.
- **Output:** Persistent CLI auth/session commands, team selection commands, and permission-aware command registration.
