   - Expect response.headers['x-session-token'] to be defined

2. Returns 401 for invalid systemAdminKey:
   - POST to /v1/auth/login with payload `{ systemAdminKey: 'wrong-key-value' }`
   - Expect statusCode 401

   - Use separate app without systemAdminKey config: `buildServer()`
   - POST to /v1/auth/login with payload `{ systemAdminKey: 'any-key' }`
   - Expect statusCode 500 (system_admin_not_configured)

   - POST to /v1/auth/login with payload `{ accessKey: 'invalid_key_that_is_16_chars' }`
   - Expect statusCode 401

5. Returns 200 with session for valid access key:
   - Setup: In store.transact(), create user, team, membership, and access key (using hashSecret of a known token like 'test-access-key-001')
   - POST to /v1/auth/login with payload `{ accessKey: 'test-access-key-001' }`
   - Expect statusCode 200
   - Expect response.json().session to be defined
   - Expect response.headers['x-session-token'] to be defined

**describe('GET /v1/auth/session')**

6. Returns authenticated=false when no token provided:
   - GET /v1/auth/session without authorization header
   - Expect response.json().authenticated to be false

7. Returns authenticated=true with valid session:
   - Setup: Create session in store.transact() (user + team + membership + session record with known token)
   - GET /v1/auth/session with `authorization: 'Bearer <sessionToken>'`
   - Expect response.json().authenticated to be true
   - Expect response.json().session to have sessionId, member, effectivePermissions

**describe('POST /v1/auth/logout')**

8. Returns ok:true even without session token:
   - POST /v1/auth/logout without authorization header
   - Expect response.json().ok to be true

9. Deletes session on valid logout:
   - Setup: Create session in store.transact()
   - POST /v1/auth/logout with Bearer token
   - Expect response.json().ok to be true
   - Verify session is removed: store.snapshot() then check sessions array
