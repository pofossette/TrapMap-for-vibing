Write these describe blocks with tests:

**describe('extractGovernanceContext')**

2. Extracts securityLevel from auth.securityLevel

**describe('hasPermission')**

2. Returns false when permission is NOT in effectivePermissions
3. Returns true for 'system-admin' subjectType with matching permission

2. Throws AppError with statusCode=403 and code='forbidden' when permission is missing

4. Does not throw when multiple permissions present and one matches

1. Does NOT throw for system-admin (subjectType='system-admin') regardless of teamId
2. Does NOT throw when auth.activeTeamId matches the provided teamId
3. Throws AppError(403, 'team_mismatch') when auth.activeTeamId differs from teamId
4. Throws AppError(403, 'team_mismatch') when auth.activeTeamId is null

**describe('requireHigherLevel')**
1. Does NOT throw for system-admin regardless of targetLevel
2. Does NOT throw when caller securityLevel > targetLevel (e.g., 6 vs 5)
3. Throws AppError(403, 'insufficient_level') when caller level EQUALS targetLevel (boundary: 5 vs 5)
4. Throws AppError(403, 'insufficient_level') when caller level < targetLevel (e.g., 3 vs 5)
5. Uses nextLevel parameter: throws when securityLevel <= nextLevel even if > targetLevel
6. Default nextLevel equals targetLevel (both parameters set boundary)
