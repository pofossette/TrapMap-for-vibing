## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI caller -> server route | Untrusted edit payloads and artifact IDs enter the authenticated endpoints |
| Server response -> CLI formatter | Only filtered metadata should reach human or JSON output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-10 | S | CLI session handling | mitigate | Require session token before making any API requests. |
| T-19-11 | I | edit command visibility | mitigate | Only show edit command when `knowledge:submit` permission is present. |
| T-19-12 | T | file content handling | accept | File content is passed as-is to the server; server validates and hashes content. |
| T-19-13 | R | output formatting | accept | Text output is deterministic; JSON output is raw server response for agent consumption. |
| T-19-14 | D | history command visibility | mitigate | Only show history command when `knowledge:export` permission is present. |
</threat_model>
