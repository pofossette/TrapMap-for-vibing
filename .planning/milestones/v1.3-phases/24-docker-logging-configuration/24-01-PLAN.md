# Phase 24: Docker Logging Configuration

**Goal:** Wire Docker deployment to support file-based logging with proper volume mounts and env vars

**Gap Analysis:**

Current state:
- `docker-compose.yml`: Mounts only `.data` volume, no log volume, no LOG_* env vars
- `deploy.sh`: Creates only data directory, no LOG_* vars in generated .env
- `user-ops-log.ts`: Expects `LOG_USER_OPS_ENABLED`, `LOG_USER_OPS_DIR` env vars
- `rag-log.ts`: Expects `LOG_RAG_ENABLED`, `LOG_RAG_DIR` env vars
- `.env.example`: Already has LOG_* vars documented

Missing:
1. Volume mount for logs directory in docker-compose.yml
2. LOG_* environment variables passed through in docker-compose.yml
3. LOG_* defaults in deploy.sh generated .env
4. Logs directory creation in deploy.sh

---

## Task 1: Update docker-compose.yml with log volume mount and env vars

<read_first>
- docker-compose.yml
- packages/server/src/lib/user-ops-log.ts
- packages/server/src/lib/rag-log.ts
</read_first>

<action>
Modify docker-compose.yml to:

1. Add volume mount for logs directory:
   ```yaml
   volumes:
     - ./.data:/app/.data
     - ./logs:/app/logs
   ```

2. Add LOG_* environment variables in environment section:
   ```yaml
   environment:
     - LOG_USER_OPS_ENABLED=${LOG_USER_OPS_ENABLED:-false}
     - LOG_USER_OPS_DIR=${LOG_USER_OPS_DIR:-/app/logs/user-ops}
     - LOG_RAG_ENABLED=${LOG_RAG_ENABLED:-false}
     - LOG_RAG_DIR=${LOG_RAG_DIR:-/app/logs/rag}
     - LOG_MAX_FILE_SIZE_MB=${LOG_MAX_FILE_SIZE_MB:-10}
     - LOG_MAX_BACKUP_FILES=${LOG_MAX_BACKUP_FILES:-5}
   ```
</action>

<acceptance_criteria>
- `grep -E "volumes:" docker-compose.yml` succeeds and shows logs volume
- `grep "./logs:/app/logs" docker-compose.yml` succeeds
- `grep "LOG_USER_OPS_ENABLED" docker-compose.yml` succeeds
- `grep "LOG_RAG_ENABLED" docker-compose.yml` succeeds
- `grep "LOG_USER_OPS_DIR" docker-compose.yml` succeeds
- `grep "LOG_RAG_DIR" docker-compose.yml` succeeds
- `grep "/app/logs/user-ops" docker-compose.yml` succeeds
- `grep "/app/logs/rag" docker-compose.yml` succeeds
</acceptance_criteria>

## Task 2: Update deploy.sh with LOG_* defaults and logs directory creation

<read_first>

</read_first>

<action>
Modify scripts/deploy.sh to:

1. Add LOGS_DIR variable near DATA_DIR:
   ```bash
   LOGS_DIR="$PROJECT_ROOT/logs"
   ```

2. Update create_env_file function to include LOG_* variables in generated .env:
   ```bash
   cat > "$ENV_FILE" << EOF
   # Server Configuration
   NODE_ENV=production
   HOST=0.0.0.0
   PORT=4000

   # API Keys (Required)
   OPENAI_API_KEY=your-openai-api-key-here

   # Admin Security (Required - generate with: openssl rand -hex 32)
   TRAPMAP_SYSTEM_ADMIN_KEY=$(openssl rand -hex 32)

   # Data Storage
   TRAPMAP_DATA_FILE=/app/.data/trapmap.json

   # Logging Configuration (Phase 24)
   LOG_USER_OPS_ENABLED=false
   LOG_USER_OPS_DIR=/app/logs/user-ops
   LOG_RAG_ENABLED=false
   LOG_RAG_DIR=/app/logs/rag
   LOG_MAX_FILE_SIZE_MB=10
   LOG_MAX_BACKUP_FILES=5
   ```

   ```bash
   create_logs_dir() {
       mkdir -p "$LOGS_DIR"
   ```

   ```bash
   create_logs_dir
   ```
</action>

2. **Environment variable flow:**
