## Tasks

### Task 1: Dockerfile for Server Package ✓

Create a production-ready multi-stage Dockerfile:
- Use Node.js 22 LTS Alpine as base image
- Install pnpm via corepack
- Handle monorepo workspace dependencies (contracts package)
- Build TypeScript in a build stage
- Create minimal production image with only dist/ and production node_modules
- Expose port 4000
- Entry point: `node dist/index.js`

**Commit:** de1934f

### Task 2: .dockerignore Files ✓

Create package-level and root-level .dockerignore files to exclude:
- `node_modules/`
- `dist/`
- `*.test.ts`
- `*.log`
- `.env*`
- `coverage/`

**Commit:** 243117b

### Task 3: docker-compose.yml ✓

Create docker-compose.yml for local development:
- Build server from `packages/server/Dockerfile`
- Map port 4000:4000
- Mount volume for data persistence (`./.data:/app/.data`)
- Configure environment variables:
  - `OPENAI_API_KEY` (from host env)
  - `SKILL_SHAREER_DATA_FILE=/app/.data/skill-shareer.json`
- Include healthcheck
