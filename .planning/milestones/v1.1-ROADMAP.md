## Milestone Summary

**Key Decisions:**
- Post-commit indexing pattern: Domain transaction commits first, indexing runs separately (prevents nested transactions)
- Approved-only refresh: Index updates only trigger when post-update state is 'approved'
- Adapter registration: Adapters registered once at bootstrap in service container
- Lightweight graph storage: In-memory entity and relationship tracking, no external graph database

**Issues Resolved:**
- IDX-03 gap: Review approval now triggers post-commit index creation (11-01)
- IDX-04 gap: Adapter registration exposed in service container (11-01)
- IDX-05 gap: Knowledge updates refresh indexes for approved entries (11-02)
- IDX-06 gap: Knowledge deactivation removes index state and artifacts (11-02)

**Technical Debt Incurred:**
- Adapter tests use legacy interface (upsert/remove) instead of exported helpers - test-only issue, runtime production code uses correct pipeline interfaces
