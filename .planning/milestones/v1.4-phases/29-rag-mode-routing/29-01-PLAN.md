<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External query contract -> internal strategy layer | Public mode/input fields must not silently map to unstable or undocumented internal behavior |
| Intent parsing -> router decision | Deterministic heuristics must not introduce hidden, non-reproducible path changes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-01 | T | routing contracts | mitigate | Keep public compatibility explicit and validate any new routing metadata through shared schemas. |
| T-29-02 | R | router selection | mitigate | Emit `routingReason` and `selectedMode` for every decision so regressions are explainable. |
| T-29-03 | I | fallback behavior | mitigate | Record when deterministic fallback occurs so evaluations do not misattribute behavior to the primary mode. |
</threat_model>
