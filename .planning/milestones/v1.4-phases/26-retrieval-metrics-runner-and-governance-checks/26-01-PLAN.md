<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authored eval cases -> runtime executor | Untrusted fixture expectations must not bypass shared case parsing |
| Endpoint adapters -> metric pipeline | Compatibility fallbacks must stay explicit so route defects do not become silent passes |
| Normalized hits -> metric summaries | Endpoint-specific response details must not be lost before scoring and diagnostics |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | T | case loading / runner CLI | mitigate | Parse every selected case through shared eval schemas before execution and reject unknown flags or malformed selection input. |
| T-26-02 | I | metric calculators | mitigate | Keep normalization deterministic and compute metrics from normalized IDs plus authored `idealOrder`, not from formatter output. |
| T-26-03 | R | adapter fallback path | mitigate | Record adapter type and fallback usage in every case result so a green run cannot hide route-path instability. |
| T-26-04 | D | in-process evaluator | accept | Use bounded per-case execution and root test fixtures; Phase 26 does not introduce unbounded external traffic. |
</threat_model>
