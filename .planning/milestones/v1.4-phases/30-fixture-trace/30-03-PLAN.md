    Rewrite `executeSummaryCase` in `evals/summary/run.ts` to use real execution:

    1. Import from retrieval adapters:
       - `createExecutionContext`, `closeExecutionContext` from `../retrieval/lib/adapters.js`
       - `seedScenarioFixtures`, `createActorSession`, `executeThroughRoute` from `../retrieval/lib/adapters.js`

    2. Create `loadSummaryScenario` function (pattern from retrieval's load.ts):
       - Import `summarySmokeScenariosMap` from `./scenarios/smoke/summary-smoke-scenarios.js`
       - Return scenario by scenarioId or undefined

    3. Rewrite `executeSummaryCase`:
       - Create execution context: `const ctx = await createExecutionContext()`
       - Load scenario: `const scenario = loadSummaryScenario(case_.scenarioId)`
       - If no scenario found, return early with warning
       - Seed fixtures: `await seedScenarioFixtures(ctx, case_)`
       - Set actor session: `await createActorSession(ctx, scenario.actor)`
       - Execute retrieval: `const adapterResult = await executeThroughRoute(ctx, case_)`
       - Extract raw response: `const rawResponse = adapterResult.result.rawResponse`
       - Extract summary text: `const summaryText = (rawResponse as any)?.summary?.text ?? null`
       - Build context array based on endpoint:
         - v1: `[...(rawResponse.globalConstraints || []).map((e: any) => e.detail), ...(rawResponse.projectKnowledge || []).map((e: any) => e.detail)]`
         - v2: `(rawResponse.capsules || []).map((c: any) => \`\${c.content} \${c.problem} \${c.goal}\`)`
       - Close context: `await closeExecutionContext(ctx)`
       - Pass summaryText and context to judge.evaluate()
       - Return result with new trace fields

    4. Remove `generateMockSummary` and `generateMockContext` functions entirely
  </action>
