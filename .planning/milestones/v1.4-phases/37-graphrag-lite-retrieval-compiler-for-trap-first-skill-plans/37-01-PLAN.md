    Schemas to define (use the exact schemas from 37-PATTERNS.md section "Recommended Schema for plans.ts"):

    1. `planEdgeTypeSchema` - z.enum(['risk-blocks', 'mitigates', 'requires', 'order']) -- NOTE: excludes 'co-occurs-with' because co-occurrence is citation-only, not a plan edge
    2. `planEdgeStrengthSchema` - z.enum(['hard', 'soft'])
    3. `planTrapNodeSchema` - trap node with: nodeId (entityIdSchema), sourceId (entityIdSchema), label (string 1-280), severity (planEdgeStrengthSchema), scope (scopeSchema), requiredLevel (securityLevelSchema), evidence (string min 1), score (number 0-1)
    4. `planSkillNodeSchema` - skill node with: nodeId (entityIdSchema), artifactId (entityIdSchema), capsuleId (entityIdSchema optional), label (string 1-280), situation (string 1-1000), problem (string 1-1000), goal (string 1-1000), scope (scopeSchema), requiredLevel (securityLevelSchema), score (number 0-1)
    5. `planEdgeSchema` - edge with: id (entityIdSchema), sourceNodeId (entityIdSchema), targetNodeId (entityIdSchema), type (planEdgeTypeSchema), strength (planEdgeStrengthSchema)
    6. `planCitationSchema` - citation with: sourceId (entityIdSchema), sourceKind (z.enum(['trap', 'skill'])), label (string 1-280), scope (scopeSchema), score (number 0-1)
    7. `trapFirstPlanSchema` - top-level with: blockingTraps (array of planTrapNodeSchema, default []), recommendedSkills (array of planSkillNodeSchema, default []), edges (array of planEdgeSchema, default []), citations (array of planCitationSchema, default [])
    8. `planQuerySchema` - query with: seed (string 1-2000), skillBudget (number int 1-10, default 3), maxDepth (number int 1-5, default 2)

    Export types via z.infer for all 8 schemas.

    Then add `export * from './domain/plans.js';` to `packages/contracts/src/index.ts` after the existing export lines (before the Phase 35 re-exports block at line 15).
