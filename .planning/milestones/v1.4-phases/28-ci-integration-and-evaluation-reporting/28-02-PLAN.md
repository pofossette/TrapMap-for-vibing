## Task 28-02-02: Create eval.yml GitHub Actions workflow for smoke tests on PRs

**<read_first>**
- package.json (scripts: eval:smoke, eval:retrieval:smoke, eval:summary:smoke)
- evals/scripts/eval-all.ts (runner entry point)
- evals/README.md (documentation for understanding the workflow)
**</read_first>**

**<action>**
Create `.github/workflows/eval.yml` with the following structure:

```yaml
name: Evaluation

on:
  pull_request:
    branches: [main]
    paths:
      - 'packages/contracts/src/domain/evals/**'
      - 'evals/**'
      - 'packages/server/src/**'
  workflow_dispatch:
    inputs:
      tier:
        description: 'Evaluation tier to run'
        required: false
        default: 'smoke'
        type: choice
        options:
          - smoke
          - core

jobs:
  eval-smoke:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install pnpm
        uses: pnpm/action-setup@v3
        with:
          version: 10.33.0

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Run smoke evaluation
        run: pnpm eval:smoke
        env:
          NODE_ENV: test

      - name: Upload eval report (on failure)
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: eval-report
          path: reports/
          retention-days: 7
```

The workflow should:
1. Trigger on PRs to main that modify eval-related files
2. Support manual dispatch with tier selection
3. Use pnpm for package management
4. Run the smoke evaluation
5. Upload reports artifact on failure for debugging
**</action>**

**<acceptance_criteria>**
- File `.github/workflows/eval.yml` exists
- `grep -c "pnpm eval:smoke" .github/workflows/eval.yml` returns count >= 1
- `grep -c "pull_request" .github/workflows/eval.yml` returns count >= 1
- `grep -c "workflow_dispatch" .github/workflows/eval.yml` returns count >= 1
- `grep -c "actions/upload-artifact" .github/workflows/eval.yml` returns count >= 1
**</acceptance_criteria>**

## Task 28-02-04: Create eval-ci.ts entry point for CI-specific execution

**<read_first>**
- evals/scripts/eval-all.ts (base runner to extend)
- packages/contracts/src/domain/evals/report.ts (report schemas)
- package.json (to understand output format requirements)
**</read_first>**

**<action>**
Create `evals/scripts/eval-ci.ts` that:
1. Parses `GITHUB_OUTPUT` environment variable for GitHub Actions output
2. Runs smoke or core evaluation based on `TIER` env var (default: smoke)
3. Writes JSON report to `reports/eval-report.json`
4. Sets GitHub Actions output variables:
   - `passed`: "true" or "false"
   - `total_cases`: number of cases
   - `passed_cases`: number passed
   - `failed_cases`: number failed
5. Outputs CI-friendly single-line summary using `formatCompactSummary`
6. Always writes report, even on failure (for artifact upload)
7. Exits with code 1 on failure, 0 on success

Format for CI output:
```
::group::Evaluation Results
[Summary output here]
::endgroup::
```
**</action>**

**<acceptance_criteria>**
- File `evals/scripts/eval-ci.ts` exists
- `grep -n "GITHUB_OUTPUT" evals/scripts/eval-ci.ts` returns at least 1 match
- `grep -n "reports/eval-report.json" evals/scripts/eval-ci.ts` returns at least 1 match
- `grep -n "formatCompactSummary" evals/scripts/eval-ci.ts` returns at least 1 match
- Script writes report to reports/eval-report.json when executed
- Script exits with code 1 when any case fails
**</acceptance_criteria>**

## Task 28-02-06: Add scheduled core evaluation workflow

**<read_first>**
- .github/workflows/eval.yml (existing workflow)
- package.json (eval:ci:core script)
**</read_first>**

**<action>**
Add a second job to `.github/workflows/eval.yml` for scheduled core evaluations:

```yaml
  eval-core-scheduled:
    runs-on: ubuntu-latest
    if: github.event_name == 'schedule' || (github.event_name == 'workflow_dispatch' && inputs.tier == 'core')
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install pnpm
        uses: pnpm/action-setup@v3
        with:
          version: 10.33.0

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Run core evaluation
        run: pnpm eval:ci:core
        env:
          NODE_ENV: test

      - name: Upload eval report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: eval-core-report
          path: reports/
          retention-days: 30
```

Also add to the workflow triggers:
```yaml
on:
  schedule:
    - cron: '0 6 * * 1'  # Weekly on Monday at 6 AM UTC
```
**</action>**

**<acceptance_criteria>**
- `grep -c "eval-core-scheduled" .github/workflows/eval.yml` returns count >= 1
- `grep -c "schedule:" .github/workflows/eval.yml` returns count >= 1
- `grep -c "eval:ci:core" .github/workflows/eval.yml` returns count >= 1
- Workflow has two jobs: eval-smoke and eval-core-scheduled
**</acceptance_criteria>**
