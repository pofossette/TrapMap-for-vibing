# Plan 28-01: Wire pnpm scripts, docs, and report summaries for maintainer workflows

**Requirements:** EOPS-01, EOPS-02

**Summary:** Consolidate pnpm scripts for unified evaluation entry points, enhance report formatting for cross-endpoint/mode comparison, and update documentation with clear maintainer guidance for adding cases and interpreting failures.

---

## Task 28-01-01: Create unified eval:smoke and eval:core scripts in package.json

**<read_first>**
- package.json (current scripts configuration)
- evals/retrieval/run.ts (retrieval runner entry point)
- evals/summary/run.ts (summary runner entry point)
**</read_first>**

**<action>**
Add the following scripts to `package.json` scripts section:
- `"eval:smoke": "pnpm exec tsx evals/scripts/eval-all.ts --tier smoke"` - Runs both retrieval and summary smoke tests
- `"eval:core": "pnpm exec tsx evals/scripts/eval-all.ts --tier core"` - Runs both retrieval and summary core tests
- `"eval:all": "pnpm exec tsx evals/scripts/eval-all.ts"` - Runs full evaluation suite
- `"eval:all:json": "pnpm exec tsx evals/scripts/eval-all.ts --json --json-path ./reports/eval-report.json"` - Runs with JSON output

Create `evals/scripts/eval-all.ts` that:
1. Parses `--tier` argument (smoke/core, default: smoke)
2. Parses `--json` and `--json-path` arguments
3. Executes retrieval evaluation via programmatic import of `evals/retrieval/run.ts`
4. Executes summary evaluation via programmatic import of `evals/summary/run.ts`
5. Combines outputs into a unified terminal summary showing both evaluation types
6. Writes combined JSON report if `--json` flag is set
7. Exits with code 1 if any evaluation failed, 0 otherwise
**</action>**

**<acceptance_criteria>**
- `grep -E '"eval:smoke"|"eval:core"|"eval:all"|"eval:all:json"' package.json` returns 4 matches
- File `evals/scripts/eval-all.ts` exists
- `pnpm eval:smoke` executes without error and runs both retrieval and summary smoke tests
- Combined output shows both "Retrieval Evaluation" and "Summary Evaluation" sections
- Exit code is 1 when any case fails, 0 when all pass
**</acceptance_criteria>**
