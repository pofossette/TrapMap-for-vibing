# 27-01: Define Summary Evaluation Fixtures, Judge Prompts/Config, and Execution Contract

## Requirements

- SEVAL-01: Summary evaluation flow scores groundedness, coverage, and citation adherence
- SEVAL-02: Cases define required facts and forbidden claims for judge-driven checks

## Goal

Define the summary evaluation case schema, judge configuration contracts, and initial smoke-tier datasets with required facts and forbidden claims for LLM-as-judge verification.

## Tasks

- packages/contracts/src/domain/evals/retrieval.ts (reference for schema patterns)

- packages/contracts/src/domain/evals/report.ts (report schema patterns)
</read_first>

<action>

   - `forbiddenClaims: z.array(z.string().min(1))` - claims that MUST NOT appear

   - `schemaVersion: z.literal(1)`
   - `caseId: z.string().min(1)`
   - `tier: summaryEvalTierSchema`
   - `endpoint: summaryEvalEndpointSchema`
   - `request: retrievalEvalRequestSchema` (import from retrieval.ts)
   - `scenarioId: z.string().min(1)`
   - `expected: summaryEvalExpectedSchema`
   - `tags: z.array(z.string()).default([])`

5. Export types: SummaryEvalTier, SummaryEvalEndpoint, SummaryEvalExpected, SummaryEvalCase

Update `packages/contracts/src/index.ts` to add:
```typescript
export * from './domain/evals/summary.js';
```
</action>
