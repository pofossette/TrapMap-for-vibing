# Plan 63-03: Service Integration

<threat_model>
## Threat Model (ASVS L1)

| Threat ID | Description | Mitigation |
|-----------|-------------|------------|
| T-63-06 | Unauthorized repository access | Repository only created when PostgreSQL pool available (production) |
| T-63-07 | Missing repository fallback | InMemoryRepository used when no pool; existing store.transact still works |

</threat_model>

## Objective

Integrate the artifact repository into the service layer:
- Add `artifactRepo` to `SkillShareerServices` interface
- Initialize repository in `app.ts` onReady hook
- Update `createSkillArtifactRecord()` to use repository when available
- Update `appendSkillArtifactRevision()` to use repository when available
- Update `applyDerivedArtifactOutputs()` to use repository when available

### Task 63-03-03: Update createSkillArtifactRecord to use repository

<read_first>
- packages/server/src/lib/artifacts/model.ts (createSkillArtifactRecord function)
- packages/server/src/lib/artifacts/repository.ts (ArtifactRepository interface)
</read_first>

<action>
Update `packages/server/src/lib/artifacts/model.ts`:

1. Add import for ArtifactRepository type:
```typescript
import type { ArtifactRepository } from './repository.js';
```

2. Update `createSkillArtifactRecord` function signature to accept optional `artifactRepo`:
```typescript
export function createSkillArtifactRecord(args: {
  store: SkillShareerStore;
  data: StoreData;
  artifactRepo?: ArtifactRepository; // Add optional repository
  ownerUserId: string;
  // ... rest of args
}): ServerSkillArtifactRecord {
```

3. Update the function body to use repository when available:
```typescript
// Generate ID using repository if available
const artifactId = args.artifactRepo
  ? await args.artifactRepo.nextId()
  : args.store.nextId(args.data, 'artifact');

// ... build artifact record with artifactId ...

// Persist using repository if available, otherwise use store.transact
if (args.artifactRepo) {
  await args.artifactRepo.insert(artifact);
} else {
  if (!args.data.skillArtifacts) {
    args.data.skillArtifacts = [];
  }
  args.data.skillArtifacts.push(artifact);
}

return artifact;
```

Note: The function currently mutates args.data directly. With repository, we need to:
- Make ID generation async (the function becomes async)
- Not mutate args.data when using repository
</action>

<acceptance_criteria>
- `model.ts` contains `import type { ArtifactRepository } from './repository.js'`
- `createSkillArtifactRecord` accepts optional `artifactRepo` parameter
- When `artifactRepo` provided, uses `nextId()` and `insert()` methods
- When `artifactRepo` not provided, falls back to existing store mutation
- `pnpm typecheck` exits 0
