## Context

Wave 1 added the boundary context and explanation fields to the API contracts. Now we need to wire these through the retrieval pipeline:

1. Thread `boundaryContext` from the parsed query to the assembly functions
2. Build `boundaryExplanation` for each scored entry and attach it to the retrieval match

The `buildBoundaryExplanation()` function already exists in `boundary-match.ts` - we just need to call it during assembly.

     scoredEntry: ScoredEntry,
     filters: RetrievalQuery['filters'],
     citation?: RetrievalCitation,
     conflicts?: ConflictHint[],
   ): RetrievalMatch {
     const { entry, score, boundaryExplanation } = scoredEntry;
     return retrievalMatchSchema.parse({

       requiredLevel: entry.requiredLevel,
       shortcut: entry.shortcut,

       ...(boundaryExplanation ? { boundaryExplanation } : {}),
     });
   }
