## Context

Phase 54 implemented internal boundary matching logic but did NOT wire the boundary schemas into the public API contracts. The `boundaryContextSchema` and `boundaryExplanationSchema` exist in `boundary.ts` but are not added to `retrievalQuerySchema` or `retrievalMatchSchema`.

This plan adds the boundary context input field to the retrieval query schema and the boundary explanation output field to the retrieval match schema.
