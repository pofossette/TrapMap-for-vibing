# Phase 83-04: Migrate teams.ts and members.ts to Repository Pattern

## Objective

Migrate routes/teams.ts and routes/members.ts to use TeamRepository, MembershipRepository, and UserRepository instead of direct store.transact() calls.

## Context

From 83-RESEARCH.md:
- teams.ts uses store.transact() for team creation (lines 37-70) and store.snapshot() for listing (lines 14-27)
- members.ts uses store.transact() for member creation (lines 23-61) and updates (lines 76-106)
- session.ts resolveAuthContext accesses users, teams, memberships arrays
