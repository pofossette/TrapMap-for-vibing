# Phase 83-02: Migrate auth.ts Routes to Repository Pattern

## Objective

Migrate routes/auth.ts and lib/session.ts to use SessionRepository and AccessKeyRepository instead of direct store.transact() calls.

## Context

From 83-RESEARCH.md:
- auth.ts currently uses store.transact() for session CRUD (lines 31-36, 106-118)
- session.ts contains createSession, deleteSession, resolveAuthContext, findAccessKeyByToken functions
- All these functions access store directly or via transact()
