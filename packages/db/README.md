# @trapmap/db — Unified Persistence Package

> **Single source of truth** for all Drizzle PostgreSQL table definitions, column factories, and database migration.

This package consolidates the former `packages/persistence-schema` and the 7 per-service `drizzle/` directories into one place. All service packages (`service-identity-access`, `service-knowledge-write`, `service-knowledge-read`, `service-candidate-ingestion`, `service-governance-review`, `service-job-runtime`, `service-cron`) now import tables via `@trapmap/db` instead of `@trapmap/persistence-schema`.

## Structure

- `src/schema/` — Drizzle `pgTable` definitions (auth, candidates, knowledge, artifacts, labels, cron, queue, retrieval, experience-genes, column-factories, etc.)
- `src/schema/index.ts` — barrel re-export
- `src/client.ts` — `createDb(pool: Pool)` / `createTestDb` helpers wrapping `drizzle-orm/node-postgres`
- `src/migrate.ts` — `runMigrations(pool: Pool)` reads `migrations/schema.sql` and executes it via `pool.query`; `runDbMigrations` alias for backwards compat
- `migrations/schema.sql` — single SQL file containing all `CREATE TABLE IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`, and `CREATE SEQUENCE` statements (no versioned `0000_...` history)
- `test/` — schema integrity and migration tests (separate test directory per monorepo convention)

## Migration

The old versioned evolution (`0000_youthful_gargoyle.sql`, `0001_...`, `meta/_journal.json`, etc.) has been removed. The single `schema.sql` is the source of truth, generated by merging all previous `CREATE TABLE` statements and adding `IF NOT EXISTS` guards for idempotency.

Service-level `migrations.ts` files now are thin wrappers delegating to `runMigrations(pool)` from `@trapmap/db`; the `assertOwnerMigrationSet` per-owner journal check is deprecated.

## Usage

```ts
import { knowledgeEntries, skillArtifacts, createDb, runMigrations } from '@trapmap/db';
import { Pool } from 'pg';

const pool = new Pool({ connectionString: process.env.DATABASE_URL });
await runMigrations(pool); // idempotent, IF NOT EXISTS guarded
const db = createDb(pool);
await db.select().from(knowledgeEntries).limit(10);
```

## Testing

```bash
pnpm --filter @trapmap/db test --run
pnpm --filter @trapmap/db typecheck
```
